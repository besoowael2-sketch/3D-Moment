🎂 A Birthday World — An Interactive 3D Experience

An interactive 3D birthday experience built to turn a special day into a small virtual world filled with memories, surprises, and personal touches.

The experience begins with a black screen where a birthday message appears line by line, revealing a simple but meaningful idea: a whole world was created just for one person.

As the introduction ends, a beautifully arranged birthday scene comes to life.

✨ Features

• Cinematic Intro: A black-screen opening with animated text that gradually reveals the birthday message.
• Interactive 3D Environment: A birthday-themed scene designed to create an immersive and personal experience.
• 3D Birthday Cake: A rotating cake model imported in GLB format and displayed as the centerpiece of the scene.
• Custom Table Scene: A 3D table setup that brings the birthday environment together.
• Memory Frames: Three picture frames displaying personal photos, adding a nostalgic and emotional touch to the experience.
• Interactive Birthday Card: A digital greeting card placed beside the cake that opens to reveal a special birthday message.
• Personalized Visual Design: A custom background and carefully arranged scene elements that create a unique atmosphere.
• Web-Based Experience: Designed to run directly in a web browser without requiring a separate application.

🛠️ Technologies Used

• Three.js — 3D rendering and scene creation.
• JavaScript — Scene logic, animations, and interactions.
• HTML5 — Web page structure.
• CSS3 — Styling and visual presentation.
• GLB / glTF — Loading and displaying 3D models.

🎬 Experience Flow

1. The Beginning: The screen starts completely black.
2. The Message: Animated text appears, introducing the idea of a world built especially for the birthday person.
3. The Reveal: The birthday scene appears, featuring a table and a 3D cake.
4. The Details: Three photo frames reveal personal memories around the scene.
5. The Surprise: An interactive birthday card opens to reveal a personalized greeting.

🎯 Project Goal

The goal was to create something more personal than a traditional birthday webpage by combining 3D graphics, animation, storytelling, and interaction into one cohesive experience.

Instead of simply displaying a birthday message, the project turns the greeting into a small journey that the visitor can explore.

🚀 Getting Started

1. Clone or download the repository.
2. Open the project folder in your code editor.
3. Run the project using a local development server, such as the Live Server extension in VS Code.
4. Open the provided local URL in your browser.

Running the project through a local server is recommended for proper loading of 3D assets and other resources.
